# 🎓 Smart Student Task Manager

> 一个智能、美观、功能强大的学生任务管理器，支持数据分析、图表统计、任务分类、优先级管理等。

## 🚀 功能亮点

- ✅ 用户注册/登录系统
- ✅ 任务增删改查 + 优先级/截止日期管理
- ✅ 高级数据分析面板（饼图、柱状图、完成率）
- ✅ 响应式 UI + 主题切换（亮/暗模式）
- ✅ 数据持久化存储（JSON）
- ✅ 单元测试覆盖

## 🛠 安装与使用

1. 克隆项目：

bash

git clone https://github.com/yourusername/task-manager.git

cd task-manager


2. 创建虚拟环境（推荐）：

bash

python -m venv venv

source venv/bin/activate  # Windows: venv\Scripts\activate


3. 安装依赖：

bash

pip install -r requirements.txt


4. 运行程序：

bash

python main.py
